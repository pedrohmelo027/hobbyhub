# HobbyHub

O **HobbyHub** é um projeto acadêmico de aplicação web para compartilhar atividades de lazer e descobrir novos hobbies. A proposta é aproximar pessoas com interesses em comum e incentivar o registro de experiências.

## O problema

A Visão do projeto identifica a dificuldade de encontrar pessoas que compartilham os mesmos interesses e a falta de um espaço dedicado ao compartilhamento de atividades de lazer. Também considera o impacto do uso passivo de redes sociais sobre a descoberta de novas atividades.

## O que o sistema propõe

O HobbyHub busca oferecer um espaço para publicar diários de atividades, acompanhar publicações de outras pessoas e explorar hobbies. O escopo planejado está organizado nestes casos de uso:

| Caso de uso | Descrição |
| --- | --- |
| UC01 | Cadastrar-se |
| UC02 | Realizar login |
| UC03 | Editar perfil |
| UC04 | Visualizar perfil de usuários |
| UC05 | Postar |
| UC06 | Visualizar posts |
| UC07 | Manter posts |
| UC08 | Manter tags |

## Tecnologias e restrições previstas

A Visão estabelece uma aplicação web desenvolvida em **Java** com **Spring Boot**. Também registra compatibilidade prevista com diferentes sistemas operacionais, navegadores e dispositivos.
